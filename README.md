Entry for the make.fun bounty **One-Line Roast: The Gadget You Use Every Day**. `main.ts` runs a local tournament of fourteen original one-line roasts, scored against the judge brief — funniest first, freshest second, neatest third, each with a concrete detail — and writes the winning line (82 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning roast: a robot vacuum eats its owner's charger cable, then beeps for help like it was the victim.

## Run it

```sh
node main.ts
```
